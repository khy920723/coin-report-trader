# coin-report-trader

AI 보고서로 판단하는 원화 코인 자동매매 Windows 프로그램입니다. 개인 프로젝트이고, 만드는 중입니다.

- 투자 자문이 아닙니다. AI 판단은 틀릴 수 있습니다.
- 개인용입니다. 쓰는 사람은 각자 자기 업비트 키와 자기 Claude Code 로그인으로, 자기 책임으로 씁니다.
- 아무것도 보증하지 않습니다.
- 팔거나 돈을 받고 넘기지 않습니다(업비트 Open API 이용약관 3조 2항, 6조 3항).
- 앱의 AI 사용은 쓰는 사람의 Claude 구독 사용 한도에서 빠집니다.
- 라이선스를 두지 않습니다. 코드는 보여 주기 위해 공개하며, 사용·수정·재배포할 권리를 주지 않습니다.
- `legacy/` 폴더는 이전 작업에서 옮겨 온 부품입니다. 새 구조로 옮기면서 없앱니다.
